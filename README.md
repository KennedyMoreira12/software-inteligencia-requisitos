# 📚 Software Inteligência de Requisitos

Estudo acadêmico sobre **engenharia de requisitos de software** alinhados aos objetivos de negócio, utilizando o **Processo Unificado (UP)** e modelagem de negócios baseada na arquitetura de **Eriksson e Penker**.

![Markdown](https://img.shields.io/badge/Documentação-Markdown-000000?style=for-the-badge)
![UML](https://img.shields.io/badge/UML-Modelagem-blue?style=for-the-badge)

---

## 🎯 Objetivo

Propor atividades de levantamento de requisitos baseadas na arquitetura de modelagem de negócios para serem integradas em metodologias de desenvolvimento baseadas no **Processo Unificado (UP)**, alinhando os requisitos do sistema aos objetivos reais do negócio de forma sistemática.

## 🧠 Fundamentos

- Engenharia de Requisitos e Processo Unificado (UP)
- Modelagem de processos de negócio com **UML**
- Identificação de **casos de uso** de negócio
